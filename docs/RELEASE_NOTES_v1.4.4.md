基于 chanke17/KuroCat 的独立工作模式版本；保留原作者署名和 MIT 许可证。原 fork 已更名为 KuroCatLocal。

## 本版内容

- 双击切换普通／工作模式；Codex、Claude、双工具及自动识别；真实额度、重置倒计时、任务状态与聊天跳转。
- 空格气泡变额度条／任务条，最多三条任务默认可见，更多可展开；四种状态颜色与悬浮信息。
- 自主双手打字，真实键鼠优先；短暂停顿与恢复节奏，随机生气／眩晕；等待处理时抬头提醒。
- 青轴／茶轴／红轴真实键盘录音，拎起喵叫、两类气泡弹出声，三类音量独立保存。
- 自主打字、随机表情、键盘气泡分别开关；关闭普通气泡不影响生成工作条。
- 拎起键鼠与工作条惯性、1.2秒有效甩动眩晕、四款皮肤与默认瞳色、圆润团睡和随瞳色闭眼线。
- 手动和自动回普通模式均淡出清掉已完成任务，再进入保留未处理 awaiting 和失败项；无忙碌任务30分钟自动回普通模式。

## 首次运行

退出旧版小猫，将 App 放到「应用程序」。按底部提示授权输入监控并重启；双击进入工作模式后，连接已有 Codex CLI 或登录 Claude。声音默认关闭，可在「设置 → 工作模式」开启。

目前仅提供 macOS 工作模式安装包。沿用旧版应用标识和设置路径，帮助保留设置，但更换签名可能需要重新授予输入监控；请勿和原作／KuroCatLocal 同时运行。安装包未作 Apple 公证，首次打开如被系统阻止，请在隐私与安全性中按系统提示处理。

「打开处理」仅跳转聊天，不会代替你批准操作；额度窗口以工具实际返回为准。Claude 服务及各工具数据结构可能变化，连接状态可在菜单检查。没有内置自动更新器。
